# Neovim Configuration

My personal Neovim configuration focused on productivity, efficient navigation, code editing, and a clean development environment.

## Requirements

- Neovim
- Git
- [Packer.nvim](https://github.com/wbthomason/packer.nvim)
- A [Nerd Font](https://www.nerdfonts.com/) (recommended for icons)
- A C compiler (for some Tree-sitter parsers)

## Goals

- Maintain a clean and minimal editing environment.
- Improve navigation and file management.
- Integrate Git into the editor.
- Enhance syntax highlighting.
- Improve productivity through automation and plugin integrations.
